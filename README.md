# Kitbull
Сайт-отзыв на мультфильм Kitbull (Pixar SparkShorts, 2019).

## Страницы
- `index.html` — главная
- `about.html` — о мультфильме
- `characters.html` — герои
- `reviews.html` — мой отзыв, отзывы зрителей, форма
- `gallery.html` — кадры

Стили: `styles/`, скрипты: `script.js` (сфера из символов, частицы, отзывы, лайтбокс).
